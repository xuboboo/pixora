工作流

三步，十秒

没有安装、没有注册、没有等待上传进度条。

    把图片拖进投放区，或点击选择、直接粘贴剪贴板截图。支持一次多张。

  2. 设定宽度

    点选 400 / 600 预设，或输入任意宽度；高度自动按原图比例计算。

  3. 下载 PNG

    结果卡片即刻生成，点击下载即得高清无损 PNG，文件名自动带上尺寸。

常见问题

你可能想知道

Pixora 真的完全免费吗？

是的。Pixora 是完全免费的开源项目，没有任何隐藏收费、没有试用期、没有次数限制，也不需要注册账号。

我的图片会被上传到服务器吗？

不会。所有解码、缩放与编码都在你的浏览器内通过 Canvas 完成，图片不会经过任何服务器，也不会被存储或分析。

支持哪些图片格式？

可读取 PNG、JPG、WEBP、GIF、BMP 等浏览器支持的常见格式，并可导出为 PNG（无损）、JPG 或 WEBP。

可以一次处理多张图片吗？

可以。一次拖入多张图片即可批量按同一套设置处理，每张都会单独输出结果与下载链接。

使用 Pixora 需要联网吗？

首次打开需要联网加载页面；页面加载完成后，全部处理逻辑都在本地运行，断网也能继续使用。

Pixora 和在线 PS / Photopea 有什么区别？

Pixora 专注把最高频的「改尺寸 + 导出 PNG」做成一步操作，没有复杂工具栏与上传等待；而 Photopea 这类完整编辑器适合图层级精修。两者定位互补，可搭配使用。
