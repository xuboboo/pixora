行为准则

我们希望社区对每个人都有用、友善、且不必先证明自己。

我们的承诺

作为 Pixora 的成员、贡献者和维护者，我们承诺让参与本项目的每个人都不受骚扰， 无论其年龄、体型、可见或不可见的残障、族裔、性别认同与表达、经验水平、 教育程度、社会经济地位、国籍、个人外貌、种族、宗教或性取向如何。

我们承诺以有助于营造开放、友好、多元、包容和健康社区的方式行事与互动。

我们的准则

有助于营造积极环境的行为包括：

  • 对他人展现同理心与善意
  • 尊重不同的意见、观点与经验
  • 给予并优雅地接受建设性反馈
  • 为自己的错误负责，向受影响者致歉，并从中学习
  • 关注对整个社区最有利的事，而非仅关注个人利益

不可接受的行为包括：

  • 使用带有性暗示的语言或图像，以及任何形式的性关注或挑逗
  • 挑衅、侮辱或贬损性评论，以及人身或政治攻击
  • 公开或私下的骚扰
  • 未经明确许可，发布他人的私人信息（如住址或电子邮箱）
  • 在专业场合中可被合理认定为不当的其他行为

执行责任

项目维护者有责任澄清并执行上述准则，并会对任何他们认为不当、具有威胁性、 冒犯性或有害的行为采取适当且公正的纠正措施。

维护者有权删除、编辑或拒绝与本行为准则不符的评论、提交、代码、Issue 及其他贡献， 并在适当情况下说明理由。

适用范围

本行为准则适用于所有项目空间，也适用于个人在公共场合正式代表本项目时的行为。

执行

如遇辱骂、骚扰或其他不可接受的行为，可通过 GitHub Issues 或 security.txt 中的渠道向维护者报告。 所有投诉都会被及时、公正地审查与处理。

维护者有义务尊重事件报告者的隐私与安全。

执行指南

维护者在判定违规行为的后果时，将遵循以下分级：

  1. 纠正 — 私下书面警告，说明违规性质并解释为何该行为不当。
  2. 警告 — 警告并说明持续行为的后果，在指定时间内不得与相关人员互动。
  3. 临时封禁 — 在指定时间内禁止与项目进行任何形式的互动。
  4. 永久封禁 — 永久禁止在项目内进行任何形式的公开互动。

出处

本行为准则改编自 [Contributor Covenant][homepage] 2.1 版， 可在 <https://www.contributor-covenant.org/version/2/1/code_of_conduct.html> 查阅。
