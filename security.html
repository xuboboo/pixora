安全政策

发现问题请走私密渠道，不要开公开 Issue。

支持的版本

Pixora 是一个持续发布的静态站点，只有最新版本会获得安全更新。

版本支持
1.x（最新）✅
< 1.0❌

报告漏洞

请不要通过公开 Issue 报告安全问题。

请使用以下任一私密渠道：

  • GitHub 私密漏洞报告：<https://github.com/xuboboo/pixora/security/advisories/new>
  • 或参见 .well-known/security.txt

请在报告中尽量包含：

  • 问题类型（例如 XSS、信息泄露、拒绝服务）
  • 受影响的文件与行号
  • 复现步骤或概念验证
  • 影响范围评估
  • 如有，可附上修复建议

响应时间

阶段目标时间
确认收到3 个工作日内
初步评估7 个工作日内
修复与披露视严重程度协商确定

设计上的安全承诺

Pixora 的架构本身就消除了大部分常见风险：

  • 零后端。站点是纯静态资源，没有服务器、没有数据库、没有 API 端点，因此不存在服务端注入或数据泄露面。
  • 图片不出设备。所有图像处理都在浏览器内通过 Canvas 完成，不上传、不存储、不分析。
  • 零第三方请求。页面不加载任何外部脚本、字体或分析服务，从根源上杜绝第三方供应链风险。
  • 零依赖。没有 node_modules，不存在依赖投毒或传递性漏洞。
  • 不收集数据。没有 Cookie、没有埋点、没有用户账号。

已知的非目标

以下不属于安全漏洞：

  • 用户在自己的浏览器中打开恶意构造的图片文件导致的本地问题
  • 浏览器自身实现缺陷
  • 因用户主动修改本地代码而产生的行为

致谢

我们会在修复发布后，在 CHANGELOG 中致谢报告者（除非你希望匿名）。
